## 🧑‍💻 About Me

Hello! I'm **Mokhamad Rizki Hadiono Singgih**, a web developer who works close to the backend — building the logic behind the interface: request handling, authentication, data validation, and the API endpoints the frontend depends on.

Databases get most of my attention. I design schemas, define relations between tables, and write queries that stay fast as the data grows. I'm in my fifth semester of D-IV Informatics Engineering at Politeknik Negeri Malang.

> Good applications start with a database that doesn't need fixing later.
